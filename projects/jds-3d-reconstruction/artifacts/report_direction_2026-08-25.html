两种表示互相引导时，耦合强度决定了什么

从 GS-Octree 与 MGSR 的同源性出发，经三轮收窄，落到一个代码里就摆着、论文未讨论、 且实测有效应的自由度：两条耦合通道的强度比。 本报告给出完整证据链、已确立与未确立的边界，以及三个月的实验排期。

MGSR 把两条耦合通道的权重定为 0.5 : 0.01，相差 50 倍，论文未讨论也未消融。 我们扫描这个比值，发现两支的响应方向相反：加强 geo→ref 耦合会让 被引导的外观支变差，同时让引导的几何支变好。 这不是「引导失效」，而是两支之间可测的此消彼长。

2.2 我们赖以立论的三个前提，两个被推翻

前提一：human-region 存在度量空白 已作废

原判断：OmniRe 的 28.15 / 24.36 PSNR 至今未被超越，因为后续方法只报整场景聚合指标， 行人像素被稀释（全图 37.26 与 human-region 28.15 之间有约 9 dB 落差）。

推翻它的证据：Hierarchy UGP 的 Table 2 明确报告了行人区域指标， 场景 014 重建 PSNR 从 OmniRe 的 22.16 提到 30.20，场景 023 从 29.23 提到 34.10。 这是我们自己的检索漏掉的——过度偏重 arXiv 与 2026，忽略了 2025 年的会议论文集。

前提二：被丢弃的行人「本可重建」，是模型的失败 已作废

原判断：OmniRe 丢弃大量行人，说明其 SMPL 分支存在可利用的 headroom。

推翻它的证据：我们做了分层评测并把 13 个零增益实例挂成网页逐个目视核验。 结论是被丢弃的行人绝大多数确属观测信息不足（在图像中只有几十像素高）， 9 个较大目标中 8 个已获 +2.1~+3.8 dB 增益，明确的模型失败仅 1 例（实例 40）。

这一条是研究者本人在核验界面上直接判定的，不是我们的推断。

前提三：无人做诊断——这条仍然成立，但不足以支撑一篇论文 仍成立

Hierarchy UGP 指出 OmniRe「受限于 SMPL」，但未量化为什么失败、失败多少、边界在哪。 我们已有的诊断数据：105/105 漏检发生在检测/关联阶段而非姿态拟合、43 倍的二值化容量差、 覆盖率随分辨率非单调、993 px 完全无遮挡的行人仍被漏。

但这只是诊断，不是方法。而且我们连续三次尝试为「可重建性」构造判据 （M3 v1/v2/v3）全部失败——v1 与输入无关，v2 存在偏置排除与退化阈值， v3 的方向是反的（低方差意味着塌陷到均值，不是可靠）。三次都是被我们自己的健全性检查抓出来的。

2.3 还有两个结构性不利因素

  • Hierarchy UGP 未开源。仓库仅含 README 与图片，最后一次 push 为 2024-12-20， 论文称 "We plan to release" 但至今未发。无法作为可运行基线， 任何比较只能用 component-level proxy，这在评审时是硬伤。
  • 算力与数据门槛不对称。该方向的竞争者多有车厂背景（理想汽车等）， Waymo/nuScenes 全量训练与多场景消融的成本，与单卡 4090 不在一个量级。 而当前方向在 DTU 单场景上跑一个实验点只需 40 分钟。
保留复用的资产

观测充分性分析、分层评测器（LPIPS/SSIM/PSNR 分层，含实例级掩膜与内参缩放修正）、 gpu-budget skill、以及会议全文正查工具链——后者正是当前方向调研的基础设施。 这一站的投入并未浪费。

检索工具建成后，必须能召回我们已知漏掉的那篇（Hierarchy UGP）才算可用。 实测召回得分 123，通过。没有这条标准，工具只会重复产生同样的盲区。

三条来之不易的教训

  • 局限地图只能证否，不能证成。别人论文里写的 future work 不是空位—— 写下来往往意味着已经有人在做。
  • 输入假设才是划界的关键。方法层面的相似性容易被绕开， 而「假设有 SMPL 模板」「假设观测充分」这类前提才真正决定两篇工作是否冲突。
  • 证伪成本在下降是唯一的正向信号。从两轮对话、到数小时加一次训练、 到约 20 分钟——这意味着策略应从「谨慎选一个候选深入」转为「快速证伪大量候选」。

04 当前论点：三次收窄后的表述

论点被自己的调研推翻过两次。保留演化过程，是因为最终版本的可信度来自它经受过的收窄。

第一版：双表示互导的成立条件无人研究已作废

被 MGSR 自己的消融推翻。Table 4 的 Model K（双向 BP）全面劣于 Model M（单向）： PSNR 36.64 vs 37.69、SSIM 0.9813 vs 0.9850。 论文解释只有一句 “bidirectional BP influences optimization of the branch which provides supervision”， 随后用 stop-gradient 绕过。现象已被报告，只是未被解释。

第二版：失效已观测但无人刻画条件已作废

被引文图找出的两篇收窄。CarGS 已解释了目标冲突的机制 （一条光线上，渲染正则要远离表面的高斯贡献增大，几何正则要它减小，此消彼长）； GEAR 已实证刻画了联合/分阶段/交替三者的差异，并命名了「误差归属歧义」。

第三版（当前）已核验

双表示互导中，耦合的强度与方向是未经研究的自由度。 目标冲突的机制已被解释（CarGS，单模型内两个损失之间）， 交替与联合的差异已被实证刻画（GEAR，几何与运动之间）， 但没有任何工作研究过：当两条耦合通道强度相差 50 倍时，增益为何流向强通道那一侧， 以及这个比值是否可调。

这一版不依赖「无人研究」这类全称断言，而指向一个具体的、代码里就摆着的、可测量的量。

05 代码审计：耦合就是两行 detach

实验之所以能直接开跑，是因为逐行确定了互导环的结构。 两条通道各只有一处耦合，都由一次 .detach() 实现。

方向位置载体有效强度
ref → geotrain.py:329 trans_color（透射色）作 geo 支伪 GT，另充当两个边缘感知平滑项的引导图 0.5 × 0.2 = 0.1
geo → reftrain.py:347 surf_depth 经 max 归一化后 L2 约束 ref 深度 0.01
  • 两条通道强度相差 10 倍，方向与 MGSR 自己报告的「渲染 +2.59 dB、几何近零」一致—— 增益流向与耦合强度方向相同。
  • ref 支的误差有三条路径进入 geo 支，不止伪 GT 一条： trans_color 还是 depth_tv 与 normal_tv 的引导图， 走 exp(-|∇I|) 权重——引导图错了，平滑就加在错误的位置。
  • MGSR 消融表的 Model K（双向 BP）就是删掉这两行。 单独删其一可得两种半双向配置，MGSR 未测过，是我们可直接补的格点。
在看到任何实验结果之前提出的机制假设

深度比较前两侧各按自身 max 归一化： out_depth_ref / out_depth_ref.max() 与 surf_depth / surf_depth.max()。 任一支出现一个离群深度，整幅图尺度即被改变，L2 比的就不是同一个量—— 它在强迫 ref 支拟合一个被错误缩放的目标。

这个嫌疑是代码审计时独立标出的，早于实验结果，非事后编造。 若经 E-β′ 确认，贡献即从「发现现象」升为「给出原因并给出修法」。

可复现性：六处不完整

公开产物存在六处不完整，其中三处直接改变数值结果： 缺预训练 SDF（GS-Octree 的 train-big.py 依赖论文第一阶段产物，未提供）、 脚本与库版本错配（VolumeRenderGaussVolSDF 的必填参数调用方没传）、 数据集读取器默认值错误（InitialFlags 空参解析，DTU 上会调 NeRF-synthetic 读取器）。

由此产生的硬约束

论文数字无法复现，因此所有对照组必须是我们自己跑出的基线。 这一点必须在论文中明确声明，也需要向 MGSR 作者索取 pretrain/ 目录与第一阶段的确切命令。

存在内部最优点：w=0.05 比 MGSR 取值好 3.6% 待确认 · 复现中

单种子下 ref 支 Chamfer 为 1.1919，比基线均值低 3.6%，约 20 倍标准差。 但只有一个种子。seed 1 已跑到 6470/20000，seed 2 与 w=0.1 排队中。

预注册判据（写于看到结果之前）：三种子均优于 w=0.01 且幅度 ≥2% → 成立， 即「MGSR 的取值不是最优」可写入论文；出现劣于基线者 → 不成立，需查该次运行是否异常。

劣化机制是 depth 的 max 归一化 未验证

验证方案 E-β′：固定 w_depth=0.5，只替换归一化方式 （改为中位数比值或最小二乘 scale+shift），其余不动。 若 ref 支不再劣化 → 机制确认且修法随之得到；若仍劣化 → 机制被证伪， 但上面两条此消彼长的发现仍然有效。

两支方向相反，这是核心发现

depth_loss 中 surf_depth 已 detach，梯度只流向 ref 支， 因此 w_depth 对 geo 支的作用是经环路的二阶效应。 该效应虽小（0.91%）但方向明确且区间不重叠—— 这个「互导」环在几何结果上是高度不对称的。

三个阶段门

时点门通过判据不通过怎么办
W3 末 G1 效应跨场景成立 至少 3/4 场景上，w=0.5 对 w=0.01 的 ref 支劣化 ≥3% 且方向一致 方向重估。若效应仅在 scan24 出现，说明是场景特性而非机制，需回到调研
W5 末 G2 机制确认 替换归一化后，w=0.5 下 ref 支劣化幅度降至 ≤1.5% 机制被证伪。此时仍有「此消彼长 + 内部最优」两个发现，改为经验性论文，但强度下降
W9 末 G3 方法有效 自适应耦合在 ≥4 个场景上同时不劣于两支各自的最优固定值 降级为分析型论文（条件刻画 + 诊断），不提方法贡献
排期的现实性说明

计算量不是瓶颈：一个实验点 40 分钟，跨场景 4 场景 × 4 权重 × 3 种子 = 48 个点 ≈ 32 GPU 小时， 单卡两三天可完成。瓶颈在 GS-Octree 那条线——它依赖向作者索取 pretrain/， 时间不可控，因此在甘特图中标为机动（虚线），不作为主线依赖。

08 风险与止损

风险严重度现状处置
单场景——全部结果来自 DTU scan24高 未解除W1–W3 跨场景验证，设为 G1 阶段门
数字不可与论文比较——用高斯中心而非 TSDF 网格中 已知W2 用 extract_mesh_tsdf.py 重评
论文数字无法复现——公开产物六处不完整中 已确认所有对照组自建基线，并在论文中明确声明
效应幅度偏小——geo 支仅 2.3 σ中 待补种子加至 n≥5；若仍不足则只报 ref 支
CarGS 是正面竞争框架——主张统一网络替代双模型中 已识别必须引用并正面回应；我们的差异在「环路动力学」而非「损失冲突」
未核验的综述——ESWA 2026 付费墙低 未解除通过学校订阅取得；它是唯一可能推翻文献位置的综述
明确的止损线

若 G1 不通过（效应不跨场景），立即停止本方向，不再寻找第四个实验来挽救。 这条写在前面，是为了避免在拿到不利数据后临时寻找解释—— 前一个方向的教训正是如此：三次为「可重建性」构造判据全部失败后， 我们仍试图从诊断数据里救出一个方向。

09 需要的支持

给导师

  1. 向 MGSR 作者索取 pretrain/ 目录与 GS-Octree 第一阶段的确切命令。 这是 GS-Octree 那条线唯一的阻塞点，且无法通过读代码绕过。
  2. 核对 MGSR 论文正文与 Table 4 的模型编号。 正文把 auto-stop 记为 Models G–J、iterations 记为 Models L and M， 而表格与表题显示恰好相反。可能是 PDF 抽取问题，也可能是笔误—— 我们引用这些数字前需要确认。
  3. 确认公开代码是否等于论文实验版本（六处不完整使这一点存疑）。

给潜在合作者

本方向的表示层工作（2DGS/3DGS/八叉树 SDF）已经就位且可运行， 合作空间在把耦合强度的结论迁移到人体与衣物的双表示场景—— 人体重建同样普遍使用「模板引导 + 自由形变」的双表示互导， 而那里的耦合强度同样是拍脑袋定的。

我们能提供的现成资产：DTU 官方评测实现（含坐标系自检）、 远程大 zip 局部抽取工具（取 DTU 真值用 141 MB 换掉 14 GB 下载）、 引文图全文核查工具链、以及一套已验证的耦合强度扫描流程。
