## 一、一句话现状

从 GS-Octree（本人）与 MGSR（导师）的同源性出发，原打算论证「双表示互导的成立条件无人研究」；
经三轮收窄后，落到一个**代码里就摆着、论文未讨论、且实测有效应**的自由度上：
**两条耦合通道的强度比**。首批实验（n=3 种子）确立了其中一半：加强该比值使 ref 支几何劣化 5.40%（30 σ），
geo 支同时改善 0.91%（2.3 σ，方向一致但强度待加种子）。噪声地板 sd 0.18%–0.39%。

---

## 二、论点（第三版）

> 双表示互导中，**耦合的强度与方向**是未经研究的自由度。
> 目标冲突的机制已被解释（CarGS，单模型内两个损失之间），
> 交替与联合的差异已被实证刻画（GEAR，几何与运动之间），
> 但没有任何工作研究过：当两条耦合通道强度相差 50 倍时（MGSR 的 `0.5 : 0.01`），
> 增益为何流向强通道那一侧，以及这个比值是否可调。

**为何是第三版**：第一版「成立条件无人研究」被 MGSR 自己的消融推翻（它已报告双向 BP 有害）；
第二版被 CarGS 与 GEAR 收窄（机制与实证已各被解释一半）。
现版不依赖「无人研究」这类全称断言，改为指向一个具体的、可测量的量。

### 3.2 MGSR 的互导环结构（逐行确定）

两条通道各只有一处耦合，**都由一次 `.detach()` 实现**：

| 方向 | 代码位置 | 载体 | 有效强度 |
|---|---|---|---|
| ref → geo | `train.py:329` | `trans_color`（透射色）作 geo 支伪 GT | `0.5 × w2(=0.2) = 0.1` |
| geo → ref | `train.py:347` | `surf_depth` 经 max 归一化后 L2 约束 ref 深度 | **`0.01`** |

- 两条通道强度相差 **10 倍**，方向与「渲染增益 +2.59 dB、几何增益近零」一致。
- ref 支误差进入 geo 支有**三条**路径：伪 GT，加上 `depth_tv` 与 `normal_tv` 两个
  边缘感知平滑项的引导图（走 `exp(-|∇I|)` 权重）。
- **MGSR 消融表的 Model K（双向 BP）就是删掉这两行 `.detach()`。**
  单独删其一可得两种半双向配置，**MGSR 未测过**。

### 3.3 实验结果（DTU scan24，n=3 种子，DTU 官方评测协议）

**噪声地板（同权重跨种子，n=3）**

| 分支 | 标准差 | 极差 |
|---|---|---|
| ref | 0.0022（**0.18%**） | 0.0044（0.36%） |
| geo | 0.0035（**0.39%**） | 0.0067（0.73%） |

| ref 支 overall | w=0.01（MGSR 原值） | w=0.5 |
|---|---|---|
| 三种子均值 | **1.2363** ± 0.0022 | **1.3031** ± 0.0108 |
| 相对变化 | — | **+5.4%（劣化）**，约 30 σ |

| geo 支 overall | w=0.01 | w=0.5 |
|---|---|---|
| 三种子均值 | **0.9148** ± 0.0035 | **0.9065** ± 0.0024 |
| 相对变化 | — | **−0.91%（改善）**，仅 **2.3 σ** |

**核心发现：两支方向相反。** 加强 geo→ref 耦合，geo 支（重建输出）改善 0.91%，
ref 支劣化 5.4%。这不是「引导失效」，是两支之间**可测的此消彼长**。

**但两者的证据强度不同，不可混为一谈：**

| 效应 | 幅度 | 相对基线 sd | 判定 |
|---|---|---|---|
| ref 支劣化 | +5.40% | **30.0 σ** | **已确立** |
| geo 支改善 | −0.91% | **2.3 σ** | **方向一致、区间不重叠，但强度不足**——需加种子至 n≥5 |

（此处更正 2026-08-25 07:00 版：原将 geo 支效应一并标为「已确立」，
以 2.3 σ 的强度而言属过度声称。）

补充事实：`depth_loss` 中 `surf_depth` 已 detach，梯度只流向 ref 支，
故 `w_depth` 对 geo 支的作用是**经环路的二阶效应**——该效应虽小（0.91%）但确实存在且可测。

## 四、待确认与未验证

| 命题 | 状态 |
|---|---|
| 存在**宽最优平台 0.05–0.2**（比 MGSR 取值大 5–20 倍），ref 支改善约 3% | **已确立**，n=3 于 0.05 与 0.1 |
| 劣化机制是 depth 的 max 归一化 | **未验证**，E-β′ 待做 |
| `w2`（ref→geo，直接作用于几何的通道）的效应 | **未扫描** |

**内部最优点的预注册判据**（写于看到结果之前）：
- 三种子均优于 w=0.01 且幅度 ≥2% → 成立，「MGSR 的 0.01 不是最优取值」可写入论文；
- 出现劣于 w=0.01 者 → 不成立，需查 seed 0 那次运行是否异常。

**机制假设**（由代码审计**先于**结果独立提出）：

```python
out_depth_ref    = out_depth_ref    / out_depth_ref.max()
surf_depth_fixed = surf_depth_fixed / surf_depth_fixed.max()
depth_loss = l2_loss(out_depth_ref, surf_depth_fixed)
```

两侧各按自身 max 归一化，比较的不是同一个量；任一支出现离群深度即改变整幅图尺度，
L2 便在强迫 ref 支拟合被错误缩放的目标。w=0.01 时损害淹没在噪声里，w=0.5 时显形。

**E-β′**：固定 `w_depth=0.5`，只替换归一化方式（中位数比值或最小二乘 scale+shift）。
若 ref 支不再劣化 → 机制确认，且**修法随之得到**；若仍劣化 → 机制被证伪，
但 3.3 的此消彼长仍是有效发现。

## 五、必须始终声明的局限

1. **单场景**。仅 DTU scan24。跨场景是否成立**未知**。
2. **用高斯中心而非 TSDF 网格**。因此 0.9148 这类**绝对值不可与论文比较**，
   仅同一流程内部可比。要出可比数需跑 `extract_mesh_tsdf.py`。
3. **无法复现论文数字**。公开产物有六处不完整，其中三处直接改变数值结果
   （缺预训练 SDF、脚本与库版本错配、数据集读取器默认值错误）。
   **故所有对照组必须是我们自己跑出的基线。**
4. MGSR 正文与表格存在模型编号疑似互换（auto-stop 与 iterations 两段），
   **引用其数字前须与作者核对**。
